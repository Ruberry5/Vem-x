# VEM X — Version 1

A mobile-first real-time multiplayer survival arena. Players create/join a four-letter room, choose one of eight crews, select a landing tile, and try to stay inside the single closing safe zone. The server owns room membership, timers, landing positions, movement validation, eliminations and the winner decision.

## Version 1 scope
- Home, lobby, 5-second rules card, 10-second drop, one safe-zone closure and winner screen.
- 2–10 players, nickname/crew selection, 4-letter room code and QR join link.
- Socket.IO realtime state broadcasts, reconnect token, host reassignment and room validation.
- No accounts, installs, loot, multiple zone stages or final tap showdown.

## Run locally
Requires Node.js 20+.

```bash
npm install
npm run dev
```

Vite runs at `http://localhost:5173`; the Socket.IO server runs at `http://localhost:3001`.

## Production hosting plan
- **WebSocket server:** Render, as a persistent Node.js Web Service running `npm start` from the repository root (or set Root Directory to `server` and Start Command to `npm start`). Render assigns a public HTTPS hostname such as `https://vem-x-realtime.onrender.com`; the Socket.IO endpoint is that same origin, using `wss://` automatically through the browser's HTTPS connection.
- **Frontend:** Vercel, importing the same repository with Root Directory `client`, Framework preset Vite, Build Command `npm run build`, Output Directory `dist`.
- Set Vercel environment variable `VITE_SERVER_URL` to the actual Render HTTPS URL. Set Render environment variable `CLIENT_ORIGIN` to the actual Vercel URL. Redeploy both after setting values.
- The actual public URLs are generated by the hosting providers when the project is deployed. They cannot be claimed or verified until deployment access is authorized and a deployment succeeds.

## Important V1 rules
The 8x8 map begins with all tiles available. The single safe zone closes to the central 4x4. Players choose one landing tile during DROP and may move one orthogonal tile at a time during SURVIVE. Players outside the closed zone are eliminated. If multiple players remain in the central zone, V1 resolves the winner by Manhattan distance to the zone centre, then earliest join time. This deterministic tie-break is intentionally simple for the first two-device playtest.
